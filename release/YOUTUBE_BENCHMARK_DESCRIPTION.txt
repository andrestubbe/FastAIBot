TITLE:
FastAIBot: JMH Benchmark - High-Throughput Conversational Bot Engine 🚀

DESCRIPTION:
Official OpenJDK JMH (Java Microbenchmark Harness) performance benchmark for FastAIBot. Evaluating raw bot initialization throughput, prompt formatting performance, and state tracking latency.

BENCHMARK RESULTS (JMH):
- Bot Initialization: Sub-microsecond setup latency
- Prompt Formatting: High-throughput thread-safe dispatch
- Memory Overhead: Capped under 16 MB heap footprint

RUN BENCHMARK LOCALLY:
Execute `run-benchmark.bat` in the repository root.

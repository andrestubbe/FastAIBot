# Changelog

All notable changes to the FastBot project will be documented here.

## [0.1.2] - 2026-08-07
### Added
- Integrated `FastString` native SIMD zero-allocation response buffer.
- Added constructor supporting configurable initial buffer capacity.

## [0.1.1] - 2026-08-07
### Changed
- Renamed project and orchestrator class from `FastBot` to `FastAIBot`.
- Streamlined `streamChat` to direct token streaming output.
- Removed legacy `FastBotOutputMixer` from core library and moved to `examples/Demo`.
- Comprehensive Javadoc documentation for all public constructors and methods.

## [0.1.0] - 2026-06-28
### Added
- Initial repository setup.
- `FastAIBot` core orchestrator class.
